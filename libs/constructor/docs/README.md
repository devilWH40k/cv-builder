# Constructor library

The [library README](../README.md) describes public entry points, configuration,
storage and CV-preview integration, assets, development, and testing.

See [storage adapters](storage.md) for the persistence contract, current IndexedDB
configuration, and how a future Firebase adapter would connect.

The editor uses `lib-*` selectors; reusable controls imported from
`angular-shared-ui` keep their `ui-*` selectors.
