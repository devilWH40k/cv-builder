Guides

Step-by-step help for using CV Builder. Select a guide to expand or collapse it.

Back up your saved CVs, folders, experiences and technologies, or move them to another device. The backup includes icons, photos and CV layout settings.

Open Import / Export

Select the Settings icon in the header, then choose Import / Export.

Export your database

  1. Save any changes in the CV editor before exporting.
  2. In the Export DB section, keep the suggested file name or enter your own. The .zip extension is added automatically.
  3. Select Export DB to download your backup. Keep the ZIP file for restoring your data or transferring it to another device.

Import a database backup

  1. Open CV Builder on the device where you want to import your data, then open Settings → Import / Export.
  2. Under Backup file, select Choose file and choose a ZIP backup exported from CV Builder. You do not need to unzip it.
  3. Leave Wipe previous data unchecked to merge the backup with your existing data. Matching CVs, folders and saved experiences are updated by ID; technologies are matched by name. New records are added.
  4. Select Import DB and wait for the success message.

Replacing your database: Select Wipe previous data only if you want to clear all saved CVs, folders, experiences and technologies before importing. Export your current database first if you want to keep a copy.

Backups can be up to 100 MB and contain up to 1,000 CVs, 1,000 folders, 1,000 saved experiences and 1,000 technologies.

Use folders to organize your saved CVs on the home page. Folders work in both list and card view and can contain CVs, but not other folders.

Create a folder

Go to the home page by selecting CV Builder in the header. Under Your CVs, select the New folder icon (a folder with a plus sign) next to the list/card view switch.

Enter a Folder name of up to 120 characters, then select Apply. Select Cancel to close without creating a folder.

The new folder appears in Your CVs. In list view, the number beside its name shows how many CVs it contains.

Move a CV into a folder

Press and hold a saved CV row or card, then drag it onto the folder. Release when the folder is highlighted. The CV moves into that folder.

Open a folder

Select a folder to open its contents. Select a CV inside to edit it. Use the close button to return to the home page.

Move a CV out of a folder

Open the folder, then drag the CV outside the dialog onto the shaded area around it. Release there to return the CV to the main Your CVs collection. To move it to another folder, close the dialog and drag the CV onto its new folder.

Press Escape while dragging to cancel the move.

Delete an empty folder

Move all CVs out of the folder first, then close the folder dialog. Select the folder's Delete folder trash icon in Your CVs, then confirm with Delete. This button is disabled while the folder contains CVs.

To keep a CV when removing it from a folder, drag it out as described above. The trash icon on a CV asks you to confirm deletion of the saved CV itself.

Save projects and work experiences in your library, then reuse them when building a CV. Your library is stored in this browser. Use Settings → Import / Export to back it up or transfer it to another device.

Save an experience from the CV editor

In the CV editor, select Add experience to create an experience block.

Enter a Company / Project name. You can also add your position, dates, technologies and project description. Select Save in the experience block to store it for future use. Saving it again updates that library entry.

Use the CV editor's main Save button to save the whole CV as well.

Load saved experiences into a CV

Select Load experiences below the experience blocks in the CV editor.

  1. Search by company or position and use the page controls to browse saved experiences.
  2. Select the eye icon to view an experience's details without editing it.
  3. Select the checkboxes for the experiences you want, then select Apply to add them to your CV. Experiences already added cannot be selected again.

The description and responsibilities are combined in the CV's project description. Save the CV to keep your changes.

Open the Experiences page

Select the Settings icon in the header, then choose Experiences.

The table shows your saved projects and their details. Scroll horizontally to see more columns. The Actions column stays on the right. Web and photo links open in a new tab.

Add, edit or delete an experience

  1. Select Add experience on the Experiences page to create a library entry, or select a row's pencil icon to edit it.
  2. Enter the required Project Name. Add a position, dates, technologies, description and other project details as needed. For an ongoing role, select I currently work here. Choose Yes or No for Is Updated.
  3. Select Add experience for a new entry or Save changes for an existing one. Select Cancel to leave without saving.

To delete a library entry, select its trash icon, then confirm with Delete. Editing or deleting a library entry does not change copies already saved in your CVs.

Import experiences from Excel

  1. Select Import next to Add experience on the Experiences page.
  2. Select Download template to download template.xlsx. Keep its column headings and fill in one experience per row. Project Name is required. Separate technologies with commas, use Yes/No or true/false for Is Updated, and use full http:// or https:// URLs for web and photo links. Columns with empty headings are ignored.
  3. Select Choose an Excel file and choose your .xlsx file. The first worksheet is used; the file can be up to 10 MB.
  4. Read the scrollable Report. Successful records appear in green; invalid records appear in red with their issues. A broken file or incorrect structure produces an error explaining the problem.
  5. When at least one record is valid, select Apply to save the valid records as new library entries. Invalid records are skipped. The dialog closes and the table shows your imported experiences.

Choosing a file only previews the import. Select Cancel to close without adding records. Each applied row creates a new experience, so importing the same rows again creates additional entries.
